# Les Jardins de Keur Fary 🌿

Site vitrine pour la maison d'hôtes **Les Jardins de Keur Fary**, située à Sébi, Sénégal — à 15 km de l'aéroport international Blaise Diagne.

## Aperçu

Le site présente les chambres, les expériences proposées, les avis clients et permet aux visiteurs de réserver directement via WhatsApp, sans commission.

## Stack

- HTML / CSS vanilla (aucune dépendance)
- Google Fonts — Cormorant Garamond + DM Sans
- Déployé via Vercel

## Structure

```
/
├── index.html
├── index.css
├── README.md
└── images/
    ├── salon.jpg
    ├── veranda.jpg
    └── jardin.jpg
```

## Déploiement

Le site est déployé automatiquement via Vercel à chaque push sur `main`.

Pour déployer sur Vercel :
1. Importer le repo depuis GitHub
2. Aucune configuration nécessaire — Vercel détecte automatiquement un projet HTML statique
3. Le site est en ligne en moins d'une minute

## Personnalisation

Avant de mettre en ligne, penser à :
- Remplacer `221XXXXXXXXX` dans `index.html` par le vrai numéro WhatsApp
- Ajouter les vraies photos dans le dossier `images/`
- Mettre à jour le lien Airbnb avec l'URL de l'annonce
